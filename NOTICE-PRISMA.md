# Prisma Web provenance

LUNO Stage 1 uses the publicly reachable Prisma Web application at:

https://prisma.ws/

This stage exists to reproduce and verify the actual web application before changing its UI or architecture.

The Android-only Prisma runtime is not copied into the browser build. This includes native Media3/ExoPlayer, FFmpeg JNI, XWalk, Android services and the Android JavaScript bridge.

Before redistributing generated Prisma Web assets publicly, verify the applicable copyright, license and terms of the upstream Prisma project and website.
