# Luno Prisma

Экспериментальный веб-интерфейс в стиле кинотеатра Prisma.

## Что есть сейчас
- Адаптивная тёмная главная страница
- Демонстрационная подборка фильмов
- Поиск по карточкам
- Карточка фильма и статус интеграции Z01

## Важно
Это стартовый прототип интерфейса, а не рабочий стриминговый сервис. Z01 пока не подключён: предоставленный `online.js` использует API Lampa, поэтому требуется отдельная совместимая адаптация и проверка источника/плеера. Не запускайте исходный скрипт напрямую в браузере: в нём есть динамическое выполнение кода (`eval`).

## Публикация
В настройках репозитория откройте **Settings → Pages** и выберите **Deploy from a branch**, branch `main`, folder `/ (root)`, если GitHub Pages ещё не настроен. После публикации сайт будет доступен по URL, показанному в Settings → Pages.
